# v0.6 Hidden narrative routing
The player's FIRST selected program seeds contacts, not morality or a permanent career.
- Judo, Archery, Sport Shooting => law-enforcement introductions.
- Karate, Taekwondo, Fencing => criminal-underworld introductions.
- Demonstrated XP selects a contact tier: 0–59 freelance/underfunded; 60–149 neighborhood; 150–239 established; 240+ elite.
- Later missions must let players cross networks and refuse offers.
- Blueprints can call GetInitialContactNetwork(), GetInitialContactTier(), and GetInitialContactDescription() on AROWWorldDirector to select dialogue and missions.
- Future work: persist exam accuracy and test mistakes for tier calculations; spawn NPC contacts and playable branch missions; compile and test in Unreal Engine.
- No Unreal build or runtime playtest has been performed.
